# 查询计划模式状态（/plan-status）

纯查询，不得修改任何文件。

1. 读 `./.planning/active.json`：
   - 文件不存在或 `mode` 为 `off` → 报告"未开启计划模式"；列出 `./.planning/` 下已有的需求目录（若有），提示可用 `/plan-start` 开启或恢复。
   - `mode` 为 `active` → 继续。
2. 读该需求的 `index.md`，输出紧凑摘要：
   - 当前需求与计划状态；
   - 当前步骤（ID + 名称 + 状态图标）；
   - 未决讨论点速览（编号 + 一句话，逐条列出）；
   - 最近变更与最后更新时间。
3. 若 `.planning/` 下有多个需求目录，附带列出全部目录及各自计划状态，方便多线程工作时核对。
